# 🎮 GameZone Retro

## 📋 Sobre o Projeto

A GameZone Retro é uma página HTML criada para uma loja de games clássicos. O site apresenta consoles nostálgicos, uma imagem da loja e uma tabela de produtos e preços.

## 🎯 Objetivo

Criar uma página simples utilizando HTML puro e praticar títulos, parágrafos, listas, imagens, links e tabelas.

## 🛠️ Tecnologias Utilizadas

- HTML5
- Visual Studio Code
- GitHub

## 📌 Funcionalidades

- Apresentação da loja.
- Lista de consoles clássicos.
- Imagem da loja.
- Tabela de produtos e preços.
- Link para visualizar os preços.
- Link para o Instagram.

## 🚀 Como Executar

1. Abra o projeto no Visual Studio Code.
2. Verifique se a imagem retro.png está na mesma pasta do HTML.
3. Abra o arquivo index.html no navegador.

## 📚 Aprendizados

Neste projeto, pratiquei os principais elementos do HTML, como títulos, parágrafos, listas, imagens, links e tabelas.
